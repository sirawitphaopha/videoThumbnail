# ส่งออกซับ ASS เป็น PGS (ซับแบบภาพของ Blu-ray ไฟล์ .sup)

ค้นเมื่อ 14 พ.ย. 2569 สำหรับ BUGS ข้อ 118 · ยังเป็นผลค้นจากฟอรัมกับหน้าโปรเจกต์ ยังไม่ได้ลองเครื่องมือจริงสักตัว

## พี่กันเคาะ

- พี่กันสั่ง *"เพิ่มระบบส่งออกเป็นซับ PGS ได้ ส่งจาก ass นี่เเหละ"*
- *"เเต่ก็บันทึกสิ่งที่เธอหามาด้วยนะ เเละเราต้องการสิ่งที่ดีที่สุด เธอลองหลายอันได้ นหลากหลายเอปเฟค เเละเราเข้าใจว่ามันมีข้อจำกัดก็ต้องเตือนด้วย"*
- แปลว่า ก่อนเลือกทาง ลองเครื่องมือหลายตัวจริงกับซับที่มีเอฟเฟกต์หลายแบบ แล้วเลือกตัวที่ได้ภาพใกล้ตอนเล่นที่สุดและเปิดในเครื่องเล่น Blu-ray ได้ · หน้าจอเตือนก่อนส่งออกว่าอะไรในซับนั้นจะเพี้ยนหรือหาย

## PGS คืออะไร ทำไมแปลงจาก ASS ตรงทุกอย่างไม่ได้

- PGS เก็บซับเป็นภาพ ไม่ใช่ข้อความ เครื่องเล่นแค่วางภาพทับหนังตามเวลา ฟอนต์ สี เอฟเฟกต์จึงถูกวาดเป็นภาพตั้งแต่ตอนส่งออก
- ข้อจำกัดของ Blu-ray ที่คนในฟอรัมพูดถึง ภาพซับที่ขึ้นพร้อมกันมีจำนวนจำกัด สีในภาพหนึ่งชุดจำกัด (จานสี) และเปลี่ยนภาพได้ไม่ถี่ทุกเฟรม
  - ซับสองบรรทัดคนละที่ที่ขึ้นพร้อมกัน (บทพูดด้านล่างกับเนื้อเพลงด้านบน) บางเครื่องมือได้แค่อันเดียว
  - เอฟเฟกต์ที่เปลี่ยนทุกเฟรม เช่น \move \fad \t คาราโอเกะ ต้องวาดใหม่ทุกเฟรม ไฟล์ใหญ่ขึ้นมาก และอาจเกินที่เครื่องเล่นรับได้
  - สีไล่โทน เงาเบลอ สีโปร่งใสหลายระดับ ต้องลดสีให้พอดีจานสี อาจเห็นขั้นสี
- ต้องเตือนบนหน้าจอก่อนส่งออก โดยดูจากซับจริงว่ามีของพวกนี้ไหม

## Subtitle Edit

- มีอยู่ที่เมนูส่งออก แล้วเลือก Blu-ray SUP (คนในฟอรัมพูดถึงรุ่น 4.0.8)
- วาดซับด้วยตัววาดของมันเอง ไม่ใช่ libass ตั้งได้ฟอนต์กับสีเดียวทั้งไฟล์
- คนในฟอรัมบอกว่าตำแหน่งกับแท็กของ ASS หายเกือบหมด (เป็นความเห็นในฟอรัม ยังไม่ได้ลองเอง)
- ผู้ใช้คนหนึ่งเจอซับบทพูดกับเนื้อเพลงที่เวลาซ้อนกันขึ้นได้อันเดียว ตั้งเป็นซับบังคับ (forced) ก็ไม่ช่วย
- ข้อสรุปเบื้องต้น ไม่เหมาะกับซับ ASS ที่จัดหน้ามา เหมาะกับซับข้อความธรรมดา

## เครื่องมือที่วาดจาก ASS ได้ครบกว่า

| เครื่องมือ | ทำอะไร | หมายเหตุ |
|---|---|---|
| ass2bdnxml (รุ่นของ cubicibo) | วาดซับด้วย libass ได้ภาพ PNG กับไฟล์ BDN XML | ใช้ฟอนต์ที่ฝังได้ ต้องส่งต่อให้ตัวอื่นทำเป็น .sup |
| ass2bdnxml (รุ่นของ mia-0 และ Masaiki) | avs2bdnxml เดิมที่เปลี่ยนมาวาดด้วย libass ไม่ต้องใช้ AviSynth | แพ็กเกจของ Arch บอกว่าทำได้ทั้ง BDN XML และ .sup |
| SUPer | รับ BDN XML กับ PNG ทำเป็น .sup ที่ตรงมาตรฐาน Blu-ray | คนในฟอรัมบอกว่าเอฟเฟกต์ซับซ้อนก็ได้ และผ่านมาตรฐาน |
| sub2bd | หน้าจอครอบ ass2bdnxml ทำ .sup จาก ASS SSA SRT | ทำให้ขั้นตอนสั้นลง |
| Spp2Pgs | แปลง .ass เป็น .sup ตรง ๆ ผ่านบรรทัดคำสั่ง มีห้องสมุดของ .NET | ยังไม่รู้ว่าวาดด้วยอะไร ต้องลองเอง |
| avs2bdnxml (รุ่นเดิมของ koroban) | วาดผ่าน AviSynth กับ VSFilter | เป็นตัวเทียบของรุ่น libass · มีรายงานเวลาคลาดราวครึ่งเฟรม |
| BDSupEdit | แก้ไฟล์ .sup ที่ได้ เช่นปรับขนาดให้ตรงความละเอียดหนัง | ใช้หลังส่งออก |

## ทางที่จะลองตอนถึงคิว

1. สร้างซับทดสอบหลายเอฟเฟกต์ใน `test-media/สร้าง/` บทพูดล่างกับป้ายบนพร้อมกัน \pos \move \fad \t คาราโอเกะ เงาเบลอ สีโปร่งใส ฟอนต์ที่ฝังในหนัง ภาษาไทยมีวรรณยุกต์ซ้อน
2. ลองทุกตัวในตาราง ที่หาไฟล์ได้จากแหล่งที่เชื่อถือได้ (GitHub ของผู้ทำ) เทียบภาพกับภาพที่ mpv เล่น ดูเวลาตรงเฟรมไหม ไฟล์ใหญ่แค่ไหน
3. ลองเปิด .sup ที่ได้ใน mpv กับเครื่องมือตรวจ แล้วรวมเข้า MKV ผ่านงานรวมไฟล์เดิม
4. ทางที่คิดไว้ วาดด้วย libass ตัวเดียวกับภาพนิ่งในหน้าแก้ซับ (subshot.rs) แล้วใช้ตัวทำ .sup ที่ผ่านมาตรฐาน · ถ้าต้องแนบเครื่องมือใหม่ จดค่า hash ใน vendor/README.md
