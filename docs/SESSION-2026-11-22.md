# บันทึก session 22 พ.ย. 2569 · แบ่งไฟล์โค้ดทั้งโปรเจกต์ · รุ่น 0.10.1.1 กับ 0.10.1.2

ทำบนเครื่องคลาวด์ (Linux) ไม่มีคอม Windows พี่กันอยู่ข้างนอก · งานคือ BUGS ข้อ 153 แบ่งไฟล์โค้ดที่ยาวเกินทั้งโปรเจกต์ ที่นัดไว้วันศุกร์

## คำสั่งของพี่กันใน session นี้

- ถามชื่อกับวิธีคุย แคลร์ข้อความแรกพูดผิดกฎ แทนตัวเองว่าผมและลงท้ายครับ บอกพี่กันแล้วว่าผิดอะไร
- *"ขึ่นเมนเท่านั้นนะ"* push ขึ้น main เท่านั้น ไม่ใช้กิ่ง claude/... ที่ระบบคลาวด์ตั้งให้
- *"ต้องเปิด plan mode ก่อนไหม แบ่งไฟล์"* แคลร์ตอบตามที่จดไว้ว่าไม่ต้อง พี่กันอธิบาย *"ที่เราบอกเปลืองเพราะตอนนั้น token จะหมด ตอนนี้มีครบแล้วนะ"* แล้วสั่ง *"เปิด plan mode เลย"*
- ระหว่างทำแผน พี่กันตอบเรื่องเครื่องที่ใช้ *"เราไม่ได้รีโมท เราอยู่ข้างนอกเลย เอาแบบเธอสร้างระบบจำลองหน้าโปรแกรมแยกออกมาเหมือนเว็บได้ไหม เอาไว้เทส ถ่ายรูป"*
- ตีแผนกลับสามรอบ *"เรื่องฟอนตโหลดมาเพิ่มได้"* · *"ชั้นสามารถแบ่งมากกว่านี้ได้ และ commit บ่อยๆ ก็เขียนเป็นขั้น 7.1 7.2"* · *"รันงานจนจบ เราจะแค่เข้ามาดูนะ ไม่หยุดถามว่าให้ทำต่อไหม"* · *"พุช 3 รอบใน 13 ขั้น ไปแบ่งเอาเอง รุ่นเอาเป็น 10.1.1-3 เพิ่มเลขอีก 1 ตัว"* · *"ระบบแบ่งไฟลื ต้องรองรับงานในอนาคตได้ ... ระบบต้องรู้ว่าถ้า code เริ่มโต ต้องแบ่ง"* · *"Plan นี้จดเป็น md ด้วย ... เสร็จขั้นไหน มาจดไว้ด้วย"* · *"เราขอรันเอเจ้นตรวจทานสุดท้าย 4 ตัว ไปแบ่งงานเอง"* · *"จะเขียน commit จะพุช อ่านสกิลกฎนี้ก่อนสำคัญมากๆ"*
- อนุมัติแผน 13 ขั้น จดเต็มใน docs/PLAN-2026-11-22-แบ่งไฟล์.md · คำพี่กันคำต่อคำอยู่ BUGS ข้อ 153 (ต่อ)

## เรื่องที่สะดุดรอบ 2

- **เทส Rust อ่านไฟล์หน้าจอด้วย include_str** สองตัวใน latest.rs (รายการนามสกุลกับลิงก์การ์ดขอบคุณ) ตัวที่สองพลาดไปตั้งแต่ขั้น 5.1 และขึ้นรุ่น 0.10.1.1 ไปแล้ว cargo test จะคอมไพล์ไม่ผ่าน แก้ใน `ecf6692` · เครื่องคลาวด์รัน cargo test ไม่ได้ ต้องรันบนคอม Windows ก่อนสร้างตัวติดตั้ง
- **vite จำที่อยู่ไฟล์เดิม** หลังย้าย api.ts หน้าจำลองขาว ตอบ 404 รีสตาร์ตแล้วปกติ
- **ช่วงบรรทัดคลาด** ใช้เลขบรรทัดที่อ่านไว้ก่อนสคริปต์เติมบรรทัด import ต่อจากนั้นคำนวณจากเครื่องหมายหัวข้อทันทีก่อนตัด
- **ตัวเติม import หยิบชื่อผิดไฟล์** ชนิด Props มีหลายไฟล์ แก้ให้เลือกไฟล์ที่เพิ่งถูกตัดก่อน
- **สัญญาณรบกวนของตัววาด** มุมเงาของการ์ดที่เลือกในหน้าตั้งค่าบางรอบสีห่าง 5 ระดับ นับแยกเป็นสัญญาณรบกวน (เพดาน 6 ระดับ)

## เรื่องที่สะดุด

- **ภาพสองรอบไม่ตรงกัน** สี่เรื่อง แก้ในตัวถ่ายภาพทีละเรื่อง ขอบมนสีห่าง 1 ระดับ (วาดเธรดเดียว) · ตัวหนังสือบนกราฟบิตเรตเป็นฟอนต์สำรอง (โหลด Sarabun ก่อน) · รูปย่อหยาบตอนเครื่องทำงานหนัก (รอรูปถอด ถ่ายซ้ำจนนิ่ง) · มุมเงาของการ์ดที่เลือกในหน้าตั้งค่าห่าง 5 ระดับ (นับเป็นสัญญาณรบกวน)
- **ข้อความ commit ขั้น 4.1 เขียนว่าภาพตรง 96 จาก 96 ทั้งที่ผลจริง 95** ตัวช่วย commit ใส่ข้อความตายตัวไม่ได้อ่านผลตรวจ แก้ข้อความก่อน push แล้วเปลี่ยนตัวช่วยให้ยกผลจริงและไม่ยอม commit ถ้าผลตรวจไม่ผ่าน
- **โลโก้หัวข้อขอบคุณหายหลังย้ายหน้าตั้งค่า** ที่อยู่ใน import.meta.glob เป็นสตริง tsc ไม่ฟ้อง ระบบจำลองจับได้
- **คอมเมนต์ติดช่วงไปผิดไฟล์** ตอนเลือกช่วงบรรทัดของหน้าความดัง เลือกเกินไปหนึ่งบรรทัด ย้ายกลับแล้ว
- **สคริปต์ตัดไฟล์** แก้สามรอบ เลขบรรทัดเลื่อนหลังลบ import · import ที่อยู่กลางไฟล์ · หาชื่อจากไฟล์ที่แยกไว้ก่อน (สคริปต์อยู่ในเครื่องคลาวด์ ไม่ขึ้น git)
