# ผลตรวจของผู้ช่วยหลังจบแต่ละขั้น

พี่กันสั่ง 6 พ.ย. 2569 *"รันตรวจ 2 ตัวหลังทุกเฟสเสร็จ"* แล้วอธิบายเพิ่ม *"เราหมายถึง ตอนงานเสร็จสิวะ"* = **ครั้งเดียวตอนงานเสร็จทั้งหมด** · ผู้ช่วยแก้โค้ดไม่ได้ เขียนผลลงไฟล์ในโฟลเดอร์นี้ระหว่างทาง
ไฟล์ `ขั้น0-*.md` มาจากรอบที่แคลร์ตีความผิดแล้วปล่อยตอนจบขั้น 0 · รอบจริงจะเป็นไฟล์ `ทั้งหมด-สเปก.md` กับ `ทั้งหมด-โค้ด.md`
แคลร์ตรวจของจริงทุกข้อก่อนเชื่อ แล้วจดลงคอลัมน์ ผลที่แคลร์ตรวจ ในแต่ละไฟล์

| ไฟล์ | ใครเขียน | ตรวจอะไร |
|---|---|---|
| `ขั้น<เลข>-สเปก.md` | ผู้ช่วยตัวที่ 1 | ของในขั้นนั้นครบและตรงกับ `docs/MOCKUP-SPEC.md` กับแผนไหม |
| `ขั้น<เลข>-โค้ด.md` | ผู้ช่วยตัวที่ 2 | บั๊ก จุดที่ทำให้ไฟล์หนังหายหรือโดนทับ และข้อใน `docs/TECH-REVIEW.md` ที่ยังไม่ได้แก้ |
