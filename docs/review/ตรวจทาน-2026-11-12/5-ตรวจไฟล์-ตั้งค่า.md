- คำเทคนิคที่ยังไม่มีปุ่ม ⓘ เช่น ค่า hash ในการ์ดแบบตรวจ DPI ความลึกสี Chroma subsampling เกณฑ์ 4.5 ในการ์ดโทน เป็นงานไล่ทั้งโปรแกรม BUGS ข้อ 23
- สวิตช์ปิดดาว ป้าย แท็ก บนชั้นวาง รอพี่กันเคาะ BUGS ข้อ 48
- หน้าตรวจไฟล์จำแบบตรวจที่เลือกไว้ ไม่เปลี่ยนตามค่าตั้งต้นที่แก้ทีหลัง เป็นไปตาม BUGS ข้อ 9 ที่ให้หน้าจำของที่เลือกไว้
- เว็บ TAK อ่านผ่าน http ไม่เข้ารหัส อ่านเลขรุ่นอย่างเดียว ไม่โหลดไฟล์ ผู้เขียนจดเหตุผลไว้ (`latest.rs:42`)
