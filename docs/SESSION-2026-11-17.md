- **ไดรฟ์ C เต็มสองรอบ ต้นเหตุคือ qBittorrent โหลด Shirobako ลง Downloads ของไดรฟ์ C** พบหลัง push พี่กันสั่งหยุดแล้วย้าย แคลร์ปิด qBittorrent ย้ายสองชุดราว 20 GB ไป D:\ แก้ที่เก็บของทุกตัวกับที่เก็บตั้งต้นเป็น D:\ แล้วเปิดให้โหลดต่อแบบย่อหน้าต่าง ไดรฟ์ C ว่างราว 9.6 GB · รอบแรกเหลือ 9 MB พี่กันอนุญาตให้ลบแคชของโปรแกรมทดสอบกับโฟลเดอร์ชั่วคราวของเทส ราว 0.9 GB แล้วสั่งล้างถังขยะ · รอบสองตอน push เหลือ 0 MB อีก ไล่ดูไฟล์ที่ถูกเขียนสามชั่วโมงล่าสุดใน AppData เจอแค่โครม 191 MB ต้นเหตุจริงยังไม่รู้ ไม่ใช่ของจากการเทส
