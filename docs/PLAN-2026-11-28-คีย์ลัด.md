# แผนคีย์ลัด 28 พ.ย. 2569 (BUGS ข้อ 162.2 กับ 162.3)

## Context
- พี่กันสั่ง 28 พ.ย. 2569 เลข 2 จากรายการ ROADMAP *"2 เอาเลย แต่สิ่งที่เราต้องการเพิ่มคือหน้าตั้งค่าที่เขียนคีย์ลัดทั้งหมด ในทุกฟังชั่น และสามารถปรับได้ มีปุ่มแก้ไข เหมือนโปรแกรมทั่วไป ทำตามเขา"*
- เลข 2 เดิม (ข้อ F21 ของผู้ช่วยตรวจทานระบบซับ 14 พ.ย.) หน้าแก้ซับ Ctrl+A เลือกทุกบรรทัดได้เฉพาะตอนโฟกัสอยู่ในตาราง F3 ค้นต่อไปใช้ไม่ได้ระหว่างหน้าต่างค้นหาเปิด
- ทำบนเครื่องคลาวด์ ตรวจผ่านระบบจำลองหน้าโปรแกรมบนเว็บ ฝั่ง Rust (ช่องค่าตั้งใหม่) ต้องรัน cargo test บนคอม

## แบบที่ใช้ (ทำตามโปรแกรมทั่วไป VS Code กับหน้าตั้งค่าคีย์ลัดของ Aegisub)
- คีย์ลัดทุกตัวของโปรแกรมอยู่ในทะเบียนกลางที่เดียว `src/lib/keymap.ts` แต่ละคำสั่งมีรหัส กลุ่ม (หน้า) ชื่อไทย คีย์ตั้งต้น
- คำสั่งหนึ่งมีได้หลายคีย์ (ทำซ้ำ Ctrl+Y กับ Ctrl+Shift+Z)
- คีย์ที่พี่กันตั้งเองเก็บในค่าตั้งของโปรแกรม ช่อง `hotkeys` (รหัสคำสั่ง ไปเป็นรายการคีย์) ฝั่ง Rust กรองค่าก่อนเก็บ ค่าที่ไม่ได้ตั้งใช้คีย์ตั้งต้น
- ตัวดักคีย์ลัดกลาง `useHotkeys` อ่านคีย์ของคำสั่งตอนกดทุกครั้ง ตั้งใหม่แล้วใช้ได้ทันทีไม่ต้องเปิดหน้าใหม่
- ตัวดักเฉพาะจุด (ตัวดูรูปเต็มจอ ตัวช่วยแปล กรอบภาพหน้าแก้ซับ ตัวดูซับรูป) ถามทะเบียนผ่าน `isKey(e, รหัส)` แทนการเขียนปุ่มตายตัว
- คีย์พื้นฐานของช่องและรายการ (ลูกศรในรายการ Enter ยืนยัน Esc ปิด Tab ย้ายช่อง) แสดงในหน้าตั้งค่าแบบอ่านอย่างเดียว พร้อมบอกว่าทำไมปรับไม่ได้

## หน้าตั้งค่า หัวข้อคีย์ลัด
- อยู่กลุ่มเครื่องมือในเมนูหัวข้อซ้าย
- ช่องค้นหาชื่อคำสั่งหรือคีย์ ตารางแยกตามหน้า ชื่อคำสั่ง คีย์ที่ใช้ ปุ่มแก้ไข
- กดแก้ไข ขึ้นหน้าต่างให้กดคีย์ใหม่ บอกคีย์ที่กดอยู่ เพิ่มคีย์ที่สองได้ ลบคีย์ได้ กลับค่าตั้งต้นของคำสั่งนี้ได้
- คีย์ชนกับคำสั่งอื่นในหน้าเดียวกัน บอกว่าชนกับคำสั่งไหน ให้เลือกย้ายคีย์มาที่นี่หรือยกเลิก
- คีย์ที่เบราว์เซอร์หรือ Windows สงวนไว้ (Alt+F4 Ctrl+W Tab Esc) ไม่ให้ตั้ง บอกเหตุผล
- คำสั่งที่ตั้งเองต่างจากค่าตั้งต้นมีป้ายบอก และมีปุ่มกลับค่าตั้งต้นทั้งหมด

## ขั้น
- ขั้น 1 ทะเบียนกลางกับช่องค่าตั้ง `hotkeys` ฝั่ง Rust (กรองค่า เทส) กับหน้าจอ
- ขั้น 2 ย้ายคีย์ลัดหน้าแก้ซับ (useSeBar lineDialogs SubGrid useVidLayer ToolDialogs) กับหน้า OCR เข้าทะเบียน แก้ Ctrl+A เลือกทุกบรรทัดได้ทุกที่ F3 ใช้ได้ตอนหน้าต่างค้นหาเปิด
- ขั้น 3 ย้ายตัวดูรูปเต็มจอกับตัวดูซับรูปเข้าทะเบียน
- ขั้น 4 หัวข้อคีย์ลัดในหน้าตั้งค่า
- ขั้น 5 ตรวจ check-bugs162 ข้อ 2 กับ 3 พิสูจน์แดง ระบบจำลองภาพหน้าอื่นไม่เปลี่ยน ตรวจทานเองแล้ว commit
