## 6. ⬜ ข้อมูลไฟล์ แยกไฟล์ ค่า hash (บรรทัด 606–722)

**ข้อมูลไฟล์** เปิดจากปุ่ม `ข้อมูลไฟล์` · ภาษาอังกฤษ จัดแบบหน้า Text ของ MediaInfo · หัวแถว `กลับไปชั้นวาง` ปกเล็ก ชื่อไฟล์ ที่อยู่ `คัดลอกข้อมูลเป็นข้อความ`
- ตัวอักษรความกว้างคงที่ สามคอลัมน์ (ชื่อ 270 px · `:` · ค่า)
- General (ไม่มีช่องติ๊ก) มี Cover: Yes · Attachments: cover.jpg
- Video ☐ `แยกเป็น .mkv` · Audio #n ☐ แยกเป็นชนิดเดิม เช่น `.ac3` `.aac` · Text #n ☐ `.srt` `.ass` · Attachment ☐ `.jpg` (File name · MIME type · Size · Dimensions) · Menu ☐ `.xml` (บทหนัง)
- ติ๊กหัวข้อไหน = แยกส่วนนั้นเป็นไฟล์ · **ไฟล์หนังเดิมไม่ถูกแตะ**

**แถบแยกไฟล์** `เลือกไว้ 3 อย่าง · Audio #1 · Text #1 · cover.jpg` · `เก็บที่ D:\หนัง\ดาวเหนือ (2023) แยกไฟล์` ปุ่ม `เปลี่ยนที่เก็บ` · ปุ่ม `แยกไฟล์ที่เลือก`
- ยังไม่ติ๊ก ปุ่มกดไม่ได้ `ยังกดไม่ได้ ติ๊กอย่างน้อย 1 อย่างในตารางก่อน`
- กำลังแยก แถวละชิ้น `เสร็จแล้ว` `กำลังทำ 40%` `รอคิว` ปุ่ม `หยุด`
- เสร็จ `แยกครบ 3 ไฟล์` ชื่อไฟล์แบบ `ดาวเหนือ (2023).Audio1.th.ac3` `ดาวเหนือ (2023).Text1.th.srt` `ดาวเหนือ (2023).cover.jpg` ปุ่ม `เปิดโฟลเดอร์ที่เก็บ`
- ชื่อชนกัน `มีไฟล์ชื่อเดียวกันอยู่แล้ว` `โปรแกรมไม่เขียนทับไฟล์เดิม` ปุ่ม `ข้ามไฟล์นี้` `ตั้งชื่อใหม่ต่อท้ายเลข 2`
- ไม่สำเร็จ `แยก Video ไม่สำเร็จ พื้นที่ในไดรฟ์ D ไม่พอ` `ต้องการ 3.9 GB แต่เหลือ 1.2 GB` / `ไฟล์ที่แยกเสร็จแล้วยังอยู่ครบ` ปุ่ม `ลองใหม่`
- คัดลอกข้อมูล `คัดลอกข้อมูลไฟล์แล้ว` `วางในแชทหรือโน้ตได้เลย` / `แถบนี้หายเองใน 3 วินาที`

**ค่า hash** อยู่ใต้ข้อมูลไฟล์ · ติ๊กได้หลายตัว MD5 ☑ SHA-1 ☐ SHA-256 ☑ CRC32 ☑ SHA-512 ☐ · ผลแถวละตัว ปุ่มคัดลอก · CRC32 ตัวพิมพ์ใหญ่ ที่เหลือตัวเล็ก
- `คำนวณเมื่อ 6 พ.ย. 2569 เวลา 15:20 · ใช้เวลา 18 วินาที · ค่า SHA-256 ถูกจำไว้ใช้ตอนตรวจแบบเร็วครั้งต่อไป`
- ปุ่ม `คำนวณใหม่` `คัดลอกทั้งหมด` `บันทึกเป็นไฟล์ .sha256`
- กำลังคำนวณ `SHA-256 · อ่านไฟล์ไปแล้ว 2.70 จาก 4.21 GB` แถบ 64% ปุ่ม `หยุด`
- วางค่าที่ได้มาแล้วตรง `ตรงกับ SHA-256 ของไฟล์นี้` `ไฟล์ครบและเหมือนต้นฉบับทุกไบต์`
- ไม่ตรง `ไม่ตรงกับ SHA-256 ของไฟล์นี้` `ไฟล์อาจโหลดมาไม่ครบหรือถูกแก้ไข` / `ต่างกันที่ 2 ตัวท้าย`
