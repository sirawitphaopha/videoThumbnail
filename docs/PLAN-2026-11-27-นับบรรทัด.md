## กติกาการนับ
- ทุกบรรทัดเป็นหนึ่งในสามชนิด โค้ดจริง คอมเมนต์ บรรทัดว่าง (เอกสาร md ชนิดแรกเรียกว่าข้อความ)
- บรรทัดว่างคือบรรทัดที่ไม่มีอะไรนอกจากเว้นวรรค
- คอมเมนต์คือบรรทัดที่มีแต่คอมเมนต์ `//` `///` `//!` `/* */` `{/* */}` `<!-- -->` และ `#` ในสคริปต์ ps1 sh py (`<# #>` ของ ps1) · บรรทัดที่มีโค้ดแล้วมีคอมเมนต์ต่อท้ายนับเป็นโค้ด
- ตัวนับรู้จักสตริง ข้อความ `"src/**/*.ts"` ในโค้ดไม่ทำให้นับบรรทัดถัดไปเป็นคอมเมนต์
- ไม่นับ รูป json ไฟล์ล็อก vendor test-media และไฟล์ที่ git ไม่ได้เก็บ

## ขั้น 1 ตัวนับ
- 1.1 `scripts/lib/line-count.mjs` จัดกลุ่มไฟล์ตามที่อยู่ และนับสามชนิดตามภาษา
- 1.2 `scripts/line-stats.mjs` ไล่ทุก commit ของ main ตั้งแต่ commit แรก นับไฟล์ ณ commit นั้นจาก git ตรง ๆ ไม่ย้อนโค้ดจริง · ไฟล์ที่เนื้อไม่เปลี่ยนใช้ผลเดิม (เก็บผลตามรหัสเนื้อไฟล์ของ git) · เลขรุ่นอ่านจาก package.json ของแต่ละ commit ปักหมุดตรง commit ที่เลขรุ่นเปลี่ยน · แถว ตอนนี้ นับไฟล์ในเครื่องที่ยังไม่ขึ้นรุ่น
- 1.3 ผลลงไฟล์ข้อมูลที่โปรแกรมอ่าน ไม่ขึ้น git (สร้างใหม่ทุกครั้ง) · ต่อเข้า `npm run dev` กับ `npm run build` ให้นับเองทุกครั้งที่เปิดโหมดพัฒนาหรือสร้างตัวติดตั้ง · `npm run stats:lines` สั่งเอง · git ไม่มีหรือพังต้องไม่ทำให้สร้างโปรแกรมล้ม
- 1.4 ข้อตรวจของตัวนับใน `scripts/check-line-stats.mjs` ตัวอย่างโค้ดทุกภาษาที่รู้คำตอบ พิสูจน์ว่าแดงกับตัวนับที่ผิด
  - สถานะ ⬜ ยังไม่ทำ
