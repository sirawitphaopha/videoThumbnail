# รายงาน 8 พ.ย. 2569 · ระดับเสียงหลังเปลี่ยนความเร็ว (ข้อ 29 ของผู้ช่วยตรวจ)

พี่กันเคาะ *"เอาตามเธอได้ เพราะยังไงเราคงเเทบไม่เอาแบบนั้นมา"* ต่อจากที่แคลร์เสนอให้มีให้เลือก ค่าเริ่มต้นเป็นแบบคืนระดับเสียง

## 1. เรื่องนี้คืออะไร

แผ่น PAL เล่นหนังเร็วขึ้นราว 4% เสียงจึงทั้งเร็วขึ้นและสูงขึ้นราว 0.7 ครึ่งเสียง · ตอนเอาเสียงพากย์จากแผ่น PAL มาใส่หนังบลูเรย์ โปรแกรมยืดเสียงให้ยาวเท่าหนัง เดิมยืดแบบคงระดับเสียง เสียงพูดจึงยังแหลมแบบแผ่น PAL

## 2. ทำอะไร

- แผงตั้งค่าเสียง พอเลือกความเร็วเสียง มีตัวเลือกใหม่ **ระดับเสียงหลังเปลี่ยนความเร็ว**
  - **คืนระดับเสียงเดิม (แนะนำ)** ค่าเริ่มต้น เล่นช้าลงแบบหมุนแผ่นช้าลง ทั้งความยาวและระดับเสียงกลับเป็นแบบก่อนทำแผ่น
  - **คงระดับเสียงแบบในไฟล์** ยืดเวลาอย่างเดียว สำหรับแผ่นที่สตูดิโอแก้ระดับเสียงมาแล้ว
- ปุ่ม ⓘ อธิบายทั้งสองแบบว่าใช้กับแผ่นแบบไหน
- ตัวช่วยหาดีเลย์ที่เสนอความเร็วมาให้ ใช้แบบคืนระดับเสียงเป็นค่าเริ่มต้นเหมือนกัน

![ตัวเลือกระดับเสียง](report-2026-11-07/เสียงซับ-ขั้น2/38-ระดับเสียงหลังเปลี่ยนความเร็ว.png)

เลือกความเร็ว 25 → 23.976 แล้วขึ้นตัวเลือกระดับเสียง แบบคืนระดับเสียงเลือกไว้ พร้อมคำอธิบายกับความยาวที่จะได้

## 3. ผลตรวจ

- เทสแปลงเสียงจริง เสียงทดสอบ 1,000 Hz ยาว 3 วินาที เปลี่ยน 25 → 23.976 · แบบคืนระดับเสียงได้ราว 959 Hz · แบบคงระดับเสียงได้ 1,000 Hz · ยาว 3.128 วินาทีทั้งคู่ (นับจุดที่คลื่นตัดศูนย์จากเสียงที่ถอดกลับ)
- เทส Rust 112/112 · หน้าเสียงและซับ 76/76 (เพิ่ม 2 ข้อ ตัวเลือกขึ้นพร้อมค่าเริ่มต้น กดคงระดับเสียงแล้วคำสั่งเปลี่ยน) · รวมไฟล์ 20/20

## 4. ยังไม่ได้ตรวจ

- ยังไม่ได้ลองกับเสียงพากย์จากแผ่น PAL จริงแล้วฟังเทียบ · ไฟล์ทดสอบเป็นเสียงที่ทำขึ้น
- การคืนระดับเสียงใช้ rubberband ตั้ง tempo กับ pitch อัตราเดียวกัน ไม่ได้ใช้การเปลี่ยนอัตราสุ่มตรง ๆ เพราะตัวกรองนั้นรับเลขอัตราสุ่มเป็นจำนวนเต็ม ความยาวจะคลาดได้ถึง 58 มิลลิวินาทีต่อหนัง 2 ชั่วโมง
