# รายงานแบ่งไฟล์โค้ดทั้งโปรเจกต์ 22 พ.ย. 2569 (BUGS ข้อ 153)

แผนกับผลตรวจทุกขั้นย่อย (เสร็จเวลาไหน ตรวจอะไรผ่าน commit ไหน) อยู่ [PLAN-2026-11-22-แบ่งไฟล์.md](PLAN-2026-11-22-แบ่งไฟล์.md) · รายงานนี้สรุปผลรวม สิ่งที่เจอระหว่างทาง ผลผู้ช่วยตรวจทาน และของที่ต้องทำต่อบนคอม Windows

## ที่มา
- ไฟล์โค้ดยาวเกินจนแคลร์และเครื่องมืออื่นอ่านยาก แก้ทีต้องอ่านทั้งก้อน เช่น หน้ากราฟเสียง 3,194 บรรทัด pgs.rs 1,932 บรรทัด และโมดูล Rust 66 ไฟล์วางรวมโฟลเดอร์เดียว
- คำเคาะของพี่กัน ย้ายโค้ดอย่างเดียว ไม่เปลี่ยนการทำงาน ไฟล์ละราวไม่เกิน 600 บรรทัดไม่นับเทส จัดโฟลเดอร์ตามระบบ แยกเทส Rust แยก CSS แล้วเทสหน้าตา ตัวตรวจกับมอคอัปไม่แบ่ง
- คำสั่ง session นี้ *"พุช 3 รอบใน 13 ขั้น ไปแบ่งเอาเอง รุ่นเอาเป็น 10.1.1-3 เพิ่มเลขอีก 1 ตัว"* · *"ระบบแบ่งไฟลื ต้องรองรับงานในอนาคตได้ และมันจะไม่เพิ่มขึ้นมาอีก ระบบต้องรู้ว่าถ้า code เริ่มโต ต้องแบ่ง"* · *"เราขอรันเอเจ้นตรวจทานสุดท้าย 4 ตัว ไปแบ่งงานเอง"*

## สิ่งที่เจอระหว่างทาง (แก้แล้วทั้งหมด)
- เทส Rust ของการ์ดขอบคุณอ่านไฟล์หน้าตั้งค่าที่ย้ายไปแล้ว cargo test จะคอมไพล์ไม่ผ่าน ขึ้น GitHub ไปในรุ่น 0.10.1.1 แก้ใน ecf6692 ก่อนรอบ 2
- โลโก้หัวข้อขอบคุณหายหลังย้ายหน้าตั้งค่า เพราะ import.meta.glob เขียนที่อยู่เป็นสตริง ระบบจำลองจับได้ แก้ในขั้น 5.1
- เครื่องมือแบ่งไฟล์ Rust ในเครื่องคลาวด์เคยย้ายไฟล์เทสของโมดูลข้างเคียงที่ชื่อขึ้นต้นเหมือนกัน (nocr_lines_tests.rs ฯลฯ) ไปด้วยตอนแบ่ง nocr.rs ตัวคอมไพล์จับได้ ถอยแล้วแก้เครื่องมือก่อนแบ่งใหม่
- เทส park_tests ของ library.rs เขียนอยู่กลางไฟล์ ขั้น 11 จึงไม่ได้แยก เจอตอนขั้น 12.16 แยกเป็น park_tests.rs แล้ว ค้นแล้วไม่มีไฟล์อื่นเหลือ
- ช่วงบรรทัดคลาดตอนตัด (api ส่วนซับ หน้า OCR nocr_text) ตัวคอมไพล์หรือสคริปต์นับจับได้ทุกครั้ง ถอยแล้วทำใหม่
- แผนเดิมจะใส่ตัวกันใน `.claude/settings.json` ของโปรเจกต์ แต่ .gitignore กันโฟลเดอร์ .claude ไว้เป็นค่าตั้งส่วนตัว จึงใช้ตัวกันก่อน commit ของ git เป็นด่านหลัก

ข้อที่แก้ (ยืนยันกับโค้ดจริงแล้วทุกข้อ)
- **R1 บั๊กจริง กล่อง ⓘ ตำแหน่งบนจอในช่องแก้ของหน้า OCR ขึ้นข้อความของหน้าต่างส่งออก** ขั้น 7.1 ย้าย POS_TIP ของหน้า OCR ไป tips.tsx แต่ OcrTable.tsx ไป import ตัวแปรชื่อเดียวกันจาก OcrExportDialog.tsx (ชนิดเดียวกัน tsc จึงจับไม่ได้ และระบบจำลองไม่ได้เปิดกล่องนี้) · แก้ให้ import จาก tips.tsx กับ hasTop จาก images.tsx แล้วคืน OcrExportDialog.tsx ให้เหมือนก่อนแบ่งทุกตัวอักษร · เพิ่มข้อตรวจใน check-ocr.mjs เลือกภาพที่ 3 ที่มีป้ายบนจอแล้วเปิดกล่องนี้ · พิสูจน์ในหน้าจำลองบนเว็บ โค้ดเดิมขึ้น "ซับแถวเดียวมีได้ตำแหน่งเดียว…" (แดง) โค้ดที่แก้ขึ้น "ซับบางภาพไม่ได้อยู่ล่างจอ…" (เขียว) · ขึ้น GitHub ไปแล้วในรุ่น 0.10.1.2
- **R2 ตัวเฝ้าขนาดไฟล์บน Windows ตกทุก commit** ที่อยู่ไฟล์บน Windows ใช้ \ ตัวกรองมอคอัปกับ tests.rs จึงไม่ทำงาน ไปนับ OcrMock.tsx กับ tests.rs สามไฟล์ · แก้ให้เทียบด้วย / เสมอ · จำลองที่อยู่แบบ Windows รุ่นเดิมตก รุ่นใหม่ผ่าน 296 ไฟล์
- **R3 ตัวกันก่อน commit อ่านไฟล์ในเครื่อง ไม่ใช่ที่ stage ไว้** แก้ให้ไฟล์ที่ stage ไว้นับเนื้อจาก index และไม่นับไฟล์ที่ยังไม่อยู่ใน git · เทสแล้ว stage 700 บรรทัดแต่ไฟล์ในเครื่องเหลือ 10 บรรทัด ตก · ไฟล์ 700 บรรทัดที่ยังไม่อยู่ใน git ไม่กัน commit
- **R4 ไฟล์ hook ได้ CRLF บน Windows** อาร์กิวเมนต์มี \r ติดท้าย โหมด --staged ไม่ทำงาน · เพิ่ม .gitattributes ให้ .githooks/* เป็น LF และตัวเฝ้าตัดช่องว่างท้ายอาร์กิวเมนต์ · ชื่อไฟล์ภาษาไทยอ่านด้วย core.quotepath=off
- **R5 ระบบจำลอง ภาพเสียงและซับ ตั้งค่าแทร็ก ไม่เคยเปิดการ์ดจริง** ตัวถ่ายหาแถวด้วย tr ซึ่งหน้าไม่มี ภาพจึงเหมือนภาพหน้าหนังทุกรอบตั้งแต่ขั้น 0 · แก้ให้หาแถวจาก data-trk และรอการ์ดขึ้น หาไม่เจอให้ฟ้อง · ภาพใหม่เห็นการ์ดตั้งค่าแทร็กครบ (สองภาพนี้จึงต่างจากชุดตั้งต้นเดิม ตั้งเป็นชุดตั้งต้นใหม่)
- **R6 ระบบจำลอง ช่องโหว่ของตัวเทียบ** web-diff เทียบไฟล์ .missing.txt ด้วยแล้ว (ชื่อคำสั่งที่พังทำให้หน้าขึ้นสภาพว่างที่หน้าตาเหมือนเดิมได้) และสองโฟลเดอร์ว่างไม่นับว่าผ่าน · web-shots เช็กว่าเซิร์ฟเวอร์ 1420 เสิร์ฟโฟลเดอร์นี้ ไม่ใช่โปรเจกต์ชุดอื่น · พิสูจน์แดงทั้งสามอย่าง
- **R7 เอกสาร** แนวทางวางไฟล์เขียนว่าคำสั่ง tauri อยู่ mod.rs เสมอ ของจริง cover/link/commands.rs rows.rs กับ merge/inspect.rs เป็นไฟล์ย่อยแบบ pub mod ลงทะเบียนด้วยที่อยู่ถึงไฟล์ย่อย แก้คำแล้ว · เติม core.ts ที่อยู่เทสอ่านไฟล์หน้าจอ (app/latest_tests.rs) และไฟล์ย่อยที่ไม่ต้องมี use super

ข้อที่ไม่แก้ พร้อมเหตุผล
- สีที่เปลี่ยนไม่เกิน 6 ระดับทั้งจอผ่านตัวเทียบได้ เป็นค่าที่ตั้งไว้กันสัญญาณรบกวนของตัววาด จดเป็นข้อจำกัดใน CLAUDE.md ให้ใช้ TOL=0 เมื่อแก้สีหรือเงา
- clickText ของ web-shots ถ้าไม่เจอข้อความตรงจะกดปุ่มที่ขึ้นต้นเหมือนกัน ภาพทุกภาพยังตรงชุดตั้งต้น ไม่ได้กดผิด คงไว้
- Playwright ไม่ได้อยู่ใน devDependencies บนคอม Windows ต้อง npm i playwright ก่อนใช้ระบบจำลอง จดในรายการต้องทำบนคอม
- `#[allow(unused_imports)]` บน `pub use commands::*;` ของ cover/link (ขั้น 12.2) ตั้งใจใส่ เพราะรุ่นจริงไม่ได้ใช้ชื่อผ่านทางนี้ มีแต่เทส ไม่มีผลตอนรัน
- `#![allow(dead_code)]` หัวไฟล์ binocr nocr nocr_text ocrfix เดิม ตอนนี้คุมแค่ mod.rs ไม่คุมไฟล์ย่อย อาจขึ้นคำเตือนได้เท่านั้น ตอนนี้ cargo check ไม่มีคำเตือน
- ของที่มองเห็นกว้างขึ้นจาก pub(crate) เป็นผลของการแยกไฟล์ ไม่มีชิ้นไหนกลายเป็น pub นอก crate
