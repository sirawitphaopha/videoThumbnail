- เลขรุ่นสี่หลักเขียนตรง ๆ ไม่ได้ เพราะ package.json Cargo.toml tauri.conf.json บังคับรูปแบบสามหลัก จึงเก็บในไฟล์เป็น `0.10.1-1` `0.10.1-2` `0.10.1-3` แล้วป้ายเลขรุ่นใต้ปุ่มย่อเมนู (Sidebar.tsx อ่านจาก package.json) เปลี่ยนขีดเป็นจุด ให้บนจอขึ้น v0.10.1.1 ตามที่พี่กันเรียก · ตัวติดตั้ง NSIS รับรูปแบบนี้ได้
- push รอบ 1 รุ่น 0.10.1.1 หลังขั้น 5 (ระบบจำลอง กราฟเสียง เสียงและซับ บิตเรต ชั้นวาง ตั้งค่า)

- 🔴 ก่อนเขียน commit แรกและก่อน push ทุกรอบ อ่านกฎให้ครบก่อน (พี่กันสั่ง *"จะเขียน commit จะพุช อ่านสกิลกฎนี้ก่อนสำคัญมากๆ"*) · สกิล commit-writing ตัวจริงอยู่บนคอมพี่กันเท่านั้น ในเครื่องคลาวด์มีสำเนาในที่เก็บความจำ อ่านทั้งไฟล์ `skill_working_with_gun.md` หมวด 4 (ด่านตรวจก่อน push 9 ข้อ) `feedback_commit_message.md` `feedback_commit_detail.md` `feedback_push_flow.md` `feedback_push_flow_evidence.md` และดูรูปแบบจาก commit ล่าสุดของโปรเจกต์ · เขียนข้อความ commit เป็นไฟล์แล้วใช้ `git commit -F` · ลงท้ายด้วยบรรทัดผู้ร่วมเขียนตามที่ระบบกำหนด
- push ทุกรอบตามขั้นตอนห้าขั้นของสกิล เอกสาร → push โค้ด → push บันทึก session → เขียนความจำ → push ความจำ ขึ้น `main` ทั้งสองที่เก็บ พร้อมตารางหลักฐาน · กวาดหากุญแจ อีเมล ไฟล์ส่วนตัวก่อน push ทุกรอบ เพราะที่เก็บเป็นสาธารณะ
- ตัวติดตั้งของแต่ละรุ่นสร้างในเครื่องคลาวด์ไม่ได้ (ต้องเป็น Windows) จดในรายงานว่าต้องสร้างบนคอมพี่กัน
