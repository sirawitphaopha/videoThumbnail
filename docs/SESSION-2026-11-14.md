## เรื่องที่สะดุด

- **เทส PGS ไม่ผ่าน ต่างจาก libass 2.19** ที่แท้ ffmpeg ขยับเวลาไฟล์ .sup ที่เริ่ม 0.5 วินาทีให้เริ่มที่ศูนย์ ต้องใส่ `-copyts` ไฟล์ .sup ถูกอยู่แล้ว
- **ขยายกรอบภาพจนเครื่องมือบนภาพเพี้ยน** แคลร์ทำเอง check-subvtools ไม่ผ่าน 10 ข้อ แก้เป็นกรอบเท่าภาพวางกลางพื้นดำ
- **ข้อความเตือน ResizeObserver ตอนเข้าชั้นวาง** ตามหาด้วยการจดทุกตัววัดหลังโหลดหน้าใหม่ ต้นเหตุตัวคิดเรื่องต่อแถวจำความกว้าง 0 ตอนหน้าซ่อน · ตัวเลือก `:has()` ที่ใส่ทีหลังทำให้โผล่ทุกรอบ เปลี่ยนเป็นคลาส
- **ตัวตรวจขึ้นกับของที่ค้าง** check-sizes ใช้ไฟล์ที่เปิดค้างในหน้ากราฟ check-av ใช้แบบการ์ดที่จำไว้ check-subvideo ขึ้นกับเมนูซ้ายพับหรือกาง แก้ให้ตั้งสภาพเอง
- **ภาพรายงานเก่าโดนเขียนทับ** ตัวตรวจหลายตัวรวม check-install เขียนทับภาพที่ commit แล้ว คืนด้วย git checkout ทีละโฟลเดอร์ก่อน commit
- **README ไม่มีหน้าแก้ซับกับ libmpv** ค้างมาตั้งแต่ commit ก่อน แก้แล้ว · รายการขอบคุณในหน้าตั้งค่ายังไม่ตรง จดเป็น BUGS 122
- ข้อความคั่นในแชทหลุดเป็นภาษาอังกฤษหลายครั้ง บอกเนื้อความเป็นภาษาไทยทุกครั้ง
