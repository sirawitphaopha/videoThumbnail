# ผลตรวจหลุมทางเทคนิค ก่อนสร้างโปรแกรมชั้นหนัง

ผู้ช่วยตรวจการออกแบบที่แคลร์ร่างไว้ เมื่อ 6 พ.ย. 2569 · แคลร์เขียนลงไฟล์นี้ตามสกิลข้อ 4.2
เรื่อง MKVToolNix ผู้ช่วยเทียบกับคู่มือรุ่น 103.0 ใน `vendor/mkvtoolnix-source` · เรื่องที่ลองรันจริงแล้วอยู่หัวข้อ ต้องลองจริงในขั้นเตรียม · เรื่องที่ยังไม่ได้ลอง เขียนกำกับไว้ทุกข้อ

สถานะ ⬜ ยังไม่ได้ทำ · 🔨 ทำไปบางส่วน · ✅ ทำแล้ว · ช่อง ทำที่ไหน บอกไฟล์ที่แก้ (อัปเดตจบขั้น 0)
