วิธีลง Icaros

ลงครั้งเดียว ไอคอนไฟล์ MKV ในหน้าต่างโฟลเดอร์จะเป็นโปสเตอร์ · ไม่ลงก็ใช้โปรแกรมชั้นหนังได้ครบ
  1. กดปุ่มข้างล่าง เปิดหน้าเว็บของผู้พัฒนา Icaros แล้วโหลดตัวติดตั้ง
  2. ติดตั้ง แล้วเปิดโปรแกรม Icaros Config
  3. กดเปิดการสร้างภาพตัวอย่าง (Thumbnailing) และดูว่ามี mkv อยู่ในรายการ
  4. กลับมาที่นี่ กดตรวจใหม่ ป้ายจะเปลี่ยนเป็นพร้อมใช้งาน

หน้า 1ตอนเปิดโปรแกรมครั้งแรก ยังไม่ได้เลือกโฟลเดอร์

ชั้นยังว่างอยู่
เลือกโฟลเดอร์ที่เก็บหนังไว้ โปรแกรมจะเรียงทุกเรื่องขึ้นชั้นให้ ไฟล์ในเครื่องไม่ถูกย้ายหรือแก้จนกว่าจะสั่งเอง

เบื้องหลังที่โปรแกรมทำ

  1. ครอบเป็น MKV ใช้เครื่องมือฟรี mkvmerge (ชุดเดียวกับ MKVToolNix) ห่อภาพ เสียง ซับ ของเดิมเข้ากล่อง MKV แล้วแนบรูปโปสเตอร์เป็นไฟล์แนบชื่อ cover.jpg · ไม่แปลงภาพใหม่ จึงเร็วและคุณภาพเท่าเดิม
  2. ส่งออกเป็น MP4 ใช้ ffmpeg ห่อภาพ เสียง ซับของเดิมเข้ากล่อง MP4 แล้วฝังรูปโปสเตอร์เป็นภาพปก · ไม่แปลงภาพใหม่เหมือนกัน · ซับหรือเสียงที่ MP4 รับไม่ได้ โปรแกรมบอกก่อนลงมือ
  3. ตรวจแบบเร็ว อ่านโครงไฟล์ MKV ว่าครบ ไม่ขาดท้าย แล้วเทียบค่า hash แบบ SHA-256 (ค่าที่คำนวณจากเนื้อไฟล์ทั้งก้อน) กับที่โปรแกรมจดไว้ครั้งก่อน ถ้าไม่ตรง แปลว่าไฟล์ถูกแก้หรือเสียไป
  4. ตรวจละเอียด ใช้ ffmpeg อ่านภาพและเสียงทุกช่วง ถ้าอ่านช่วงไหนไม่ได้ จะจดนาทีไว้ให้
  5. ชั้นวาง โปรแกรมดึงรูป cover.jpg ที่แนบในไฟล์ออกมาโชว์เอง ไม่ต้องพึ่ง Windows
เรื่องที่ต้องรู้ · Windows ไม่โชว์โปสเตอร์ที่แนบใน MKV เป็นไอคอนไฟล์เอง ต้องลงโปรแกรมเสริมฟรีชื่อ Icaros ก่อน ไอคอนในหน้าต่างโฟลเดอร์ถึงจะเป็นโปสเตอร์ · ส่วนในโปรแกรมชั้นหนัง เห็นโปสเตอร์ทุกเรื่องโดยไม่ต้องลงอะไรเพิ่ม
