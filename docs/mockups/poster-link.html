ชื่อลงท้ายแบบที่ Kodi อ่านได้ (แคลร์ตั้ง) · เปลี่ยนรูปทีหลัง ไฟล์นี้เปลี่ยนตาม · เปลี่ยนชื่อหนังในชั้นหนัง รูปเปลี่ยนชื่อตาม · มีไฟล์ชื่อนี้อยู่แล้วที่โปรแกรมไม่ได้ทำ ไม่เขียนทับ ถามก่อน

เก็บสำเนาไว้ในโปรแกรม

คัดลอกรูปที่ครอปแล้วไปไว้โฟลเดอร์ข้อมูลของโปรแกรม (AppData\Local\ชั้นหนัง) ไม่มีไฟล์เพิ่มในโฟลเดอร์หนัง · ลบหรือย้ายรูปต้นฉบับแล้วปกไม่หาย · มีแต่ชั้นหนังที่เห็น โปรแกรมอื่นไม่เห็น

จับคู่อย่างเดียว

ไม่คัดลอก รูปอยู่ชื่อเดิมที่เดิม โปรแกรมจำแค่ที่อยู่รูปแล้วดึงมาแสดง · ไม่ใช้ที่เพิ่มเลย · ย้ายหรือลบรูปต้นฉบับ ชั้นวางขึ้นว่าหารูปไม่เจอ ต้องจับคู่ใหม่
ทุกแบบ ไฟล์หนังไม่ถูกแตะ · ย้ายหรือเปลี่ยนชื่อไฟล์หนังผ่านชั้นหนัง ปกตามไป · ย้ายด้วย Explorer ในไดรฟ์เดียวกัน โปรแกรมยังตามเจอจากเลขประจำไฟล์ของ Windows (แบบเดียวกับการจับคู่เสียงซับ) ย้ายข้ามไดรฟ์ต้องจับคู่ใหม่ · เปลี่ยนแบบทีหลัง มีผลกับเรื่องที่จับคู่ใหม่ เรื่องเดิมกดย้ายให้ทีเดียวได้

พี่กันเคาะแล้วสรุปคำเคาะ 8 พ.ย. 2569

  1. เก็บรูปไว้ที่ไหน · ค่าตั้งต้นคัดลอกรูปที่ครอปแล้วไปไว้ข้างไฟล์หนัง ชื่อเหมือนหนังต่อด้วยแนวตั้งหรือแนวนอน รูปต้นฉบับอยู่ที่เดิม · เก็บในโปรแกรมกับจับคู่อย่างเดียว เลือกได้ที่หน้าตั้งค่า
  2. หน้าจับคู่ปกแยกในเมนูซ้าย · หน้าใส่โปสเตอร์คือหน้ารวมกับเสียงซับ · ชั้นวางกรองได้ว่าเรื่องไหนปกมาจากการรวม เรื่องไหนจับคู่
  3. ต้องกดยืนยันก่อนเสมอ · ยืนยันทีละเรื่อง หรือติ๊กไว้หลายเรื่องแล้วยืนยันทีเดียว · กดปิดโปรแกรมตอนยังไม่ยืนยัน ขึ้นหน้าต่างถาม และคู่ที่ติ๊กไว้จำไว้
  4. ไม่มีปรับสี · ครอป หมุน 90° พลิก ปรับเอียง
  5. ปุ่มสลับดูปกตั้งกับปกนอนทั้งชั้น ทำพร้อมกัน
แคลร์ตั้งเอง ชื่อลงท้าย -poster กับ -landscape แบบที่ Kodi อ่านได้ · ข้อจำกัด ไอคอนไฟล์ใน Windows ไม่เปลี่ยน (Icaros อ่านปกจากในไฟล์) โปรแกรมเล่นหนังไม่เห็นปกที่จับคู่ อยากให้เห็นทุกที่ใช้ปุ่มรวมเข้าไฟล์
