## ผลเทียบ Spek

พี่กันบอกจุดประสงค์ *"Spek ไอเดียเราแค่ต้องการกราฟเหมือน UI เหมือน และบันทึกภาพเหมือน ซึ่งตอนนี้ โปรแกรมเราทำได้แล้ว"* · จึงไม่เอา Spek เข้ามา

- Spek 0.8.5 ถอดเสียงด้วยไลบรารี FFmpeg ที่รวมอยู่ใน `spek.exe` ขนาด 59.4 MB ไลบรารีรุ่นเก่ากว่าของเรา สัญญา GPLv3
- ความต่างจริงคือ Spek เก็บเสียงเป็นทศนิยม โปรแกรมเราแปลงเป็น 16 bit ก่อนคำนวณ (`audiograph.rs`)

ถอดด้วย ffmpeg ตัวเดิมสองแบบ คำนวณสูตรเดียวกัน ขนาด FFT 2048 หน้าต่าง Hann ช่องซ้ายช่องเดียว

| ไฟล์ | ย่าน | แบบเรา 16 bit | แบบทศนิยม |
|---|---|--:|--:|
| เพลงจริง FLAC 96 kHz 24 bit | 100 ถึง 1,000 Hz | −44.7 dB | −44.7 dB |
| เพลงจริง | 20 ถึง 30 kHz | −100.4 dB | −100.4 dB |
| เพลงจริง | 30 ถึง 48 kHz | −119.7 dB | −119.8 dB |
| สร้างเอง 24 bit เสียง −110 dB | 1 kHz | −162.1 dB | −130.8 dB |
| สร้างเอง 24 bit เสียง −60 dB | 5 kHz | −80.9 dB | −80.9 dB |

เพลงทั่วไปแทบไม่ต่าง เสียงเบามากในไฟล์ 24 bit ของเราหายไป · พี่กันสั่ง *"เสียงเบามากในกราฟแก้เลย"* แก้แล้ว กราฟเปลี่ยนเป็นอ่านทศนิยม (`audiograph.rs`) ผลที่เก็บไว้เดิมอ่านใหม่เอง

**ยังไม่ได้ตรวจ** ไม่ได้เปิดหน้าต่าง Spek จริง เพราะเด้งขึ้นจอ ตัวเลขข้างบนจำลองวิธีของมันจากซอร์สโค้ด ไม่ใช่ค่าจากโปรแกรม Spek · รอบแรกแคลร์ผสมเสียงเป็นช่องเดียวแล้วเจอความต่าง 3 dB ทุกย่าน ซึ่งมาจากการผสม ไม่ใช่จาก Spek จึงวัดใหม่แบบช่องเดียว
