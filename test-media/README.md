# ไฟล์ทดสอบของโปรแกรมชั้นหนัง

ขึ้น git แค่ไฟล์นี้กับโฟลเดอร์ `src/` · ที่เหลือสร้างใหม่หรือโหลดใหม่ได้ และบางโฟลเดอร์เป็นของส่วนตัว

| โฟลเดอร์ | ข้างในมีอะไร | ขึ้น git |
|---|---|---|
| `src/` | ซับ th.srt en.ass กับบท chapters.txt ที่เขียนด้วยมือ สคริปต์สร้างไฟล์ทดสอบต้องใช้ | ขึ้น |
| `สร้าง/` | หนัง รูป และชุดเสียงซับ ที่ `node scripts/make-test-media.mjs` สร้าง ลบแล้วสร้างใหม่ได้ | ไม่ขึ้น |
| `จากพี่กัน/` | 🔴 รูป HEIC กับคลิปอัดหน้าจอส่วนตัวของพี่กัน | ห้ามขึ้น |
| `ซับตัวอย่าง-ffmpeg/` | ไฟล์ซับตัวอย่างทางการของ FFmpeg โหลดมาเทสตัวดูซับ (ตารางข้างล่าง) | ไม่ขึ้น เป็นไฟล์ของคนอื่น |

## ชุดเสียงซับ · `สร้าง/เสียงซับ/` (แผนเสียงและซับ ขั้น 0)
